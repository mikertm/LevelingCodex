# Leveling Codex

In-game companion for **The Leveling Codex** WoW: Forever leveling guides. It traces the talent to take each level, reminds you what to train, and sets up smart macros in one click. The Professions tab has 1–300 guides for Mining, Blacksmithing, Tailoring, Enchanting, Herbalism, Skinning, Leatherworking, Alchemy, Engineering, First Aid, Cooking, and Fishing, with a crafting window trace for guided recipes. Open it with `/codex` or the minimap book.

See [CURSEFORGE_DESCRIPTION.md](CURSEFORGE_DESCRIPTION.md) for the full feature list and [RELEASING.md](RELEASING.md) for how releases are published.

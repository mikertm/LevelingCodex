# Horde 50-60: loops, gaps, dungeon links and shopping (2026-11-14)

The owner's request covered the whole Horde route: check that the 1-60 chapters connect well and loop sensibly, and find
missing quests, optional quests, dungeon chains, and vendor or Auction House items that quests need. This file covers
levels 50-60 (`QuestHorde5060.lua`). The 30-40 and 40-50 bands had separate audits running at the same time. The first
pass for this band is `2026-11-12-horde-50-60.md`; its decisions stand unless this file changes them. Every section is
still `verified = false`.

## Sources

- **Quest facts**: quest database Forever at revision 0f7d8ad, read through `tools/questfacts.py` and batch scripts on the
  same loader. These gave names, levels, minimum levels, givers, enders, prerequisites, exclusive groups, objectives,
  item drops and vendors, and NPC and object spawns. Quest IDs, maps and flight links were checked against the client
  reference `tools/reference/forever.json` (`quests.ids`, `quests.taxi`).
- **Guide A**: the reference guide A Forever Horde chapters "49-50 Feralas" to "59-60 Winterspring/Silithus II", used for quest IDs,
  grouping, order and where items are bought. No text was taken.
- **reference guide B Forever guides**: a quest-ID gap check only. No text, order or code was taken.
- **Wowhead Forever**, for quest 615/8553 (The Captain's Cutlass). The page is ambiguous; see Check in game.
- **Tools**: `tools/questloops.py` (all five Horde races and all nine classes), `tools/questroute.py audit`, and a
  quest-log simulation built on the audit's own rules (dungeons and optional steps on and off).

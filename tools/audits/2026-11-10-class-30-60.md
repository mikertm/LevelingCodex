# Alliance class quests 30-60 (QuestClassData.lua)

Date: 2026-11-10. Branch work for the 30-60 Alliance guide. Every change lives in
`QuestClassData.lua` (new blocks after the 1-30 class quests); no route, dungeon or `Data.lua` file
changed. Nothing here is verified in game yet (`verified = false` on every new section).

## Sources

- **Which chains and in what order:** the class quest chapters of a reference guide (its "<Class>
  Class Quests" guides) and the class-filtered steps of a second reference guide's Alliance 29-60
  chapters and dungeon chapters. IDs and order only; every step text is our own.
- **Quest facts** (level, minimum level, class and race masks, givers, enders, prerequisites,
  objectives, drops, spawn areas): the Forever QuestieDB records (revision 0f7d8ad, read with
  `tools/questfacts.py` and a JSON dump of the same data). Coordinates are QuestieDB spawn points or
  the centre of a mob's spawn cluster, never the reference guides' waypoints.
- **Client reference** (`tools/reference/forever.json`): every quest ID used is in `QuestV2`.
  Checked absent: 1714 Essence of the Exile, 4785 Fine Gold Thread.
- A scan of every class-restricted, Alliance-eligible QuestieDB quest with a quest or minimum
  level of 26+ found no other class chains than the ones below. No QuestieDB quest newer than
  classic carries a class mask at those levels.

## Skipped, with reasons

- **Warlock Enchanted Gold Bloodrobe** (4736/4738 referrals, 1796, 4781-4784, 4786): 4784 needs Fine
  Gold Thread, whose quest (4785) is not in the Forever client, and 1796 needs crafted Robes of Arcana.
  The reference guides only turn in the referral. Left out until checked in game.
- **Warrior 1714 Essence of the Exile**: not in the client; the essence step says so (`uncertain`).
- **Level 60 chains that need groups or raids:** Paladin charger (7638-7648: Stratholme, Scholomance,
  Arcanite and 150 gold), Warlock Dreadsteed (7562-7631: Dire Maul ritual), Hunter Rhok'delar
  (7632-7636: Molten Core drop and four elite demons), Mage 7463 Arcane Refreshment (Dire Maul).
- **Class books from Dire Maul** (7498-7506), **Armaments of War** (8316-8382, Ahn'Qiraj),
  **dungeon set 0.5 and Zul'Gurub/Ahn'Qiraj class quests**: raid or 60 dungeon content.
- **Rogue 8249 Junkboxes Needed**: a repeatable hand-in.
- **Mage 2861/2846 Tabetha's Task / Tiara of the Deep**: not class-restricted in the data (any class
  can take it); it is Zul'Farrak dungeon content.
- **Hunter 1107 Encrusted Tail Fins** and the reference's other class-tagged route quests (684, 690,
  1301, 3161, 3444, 3503, 3421, 4512/4513, 2944/2943, 7066, 7701...): not class quests in the data; the
  reference only routes some classes differently.
- **Shaman 8410-8413** (Sunken Temple chain): Horde-only in the data.
- **Shaman level 40 quest**: the client has taxi paths named "Shaman - Level 40 Quest - Thousand
  Needles - A", but no quest ID, giver or objective for it is in QuestieDB or either reference guide.
  Open question.

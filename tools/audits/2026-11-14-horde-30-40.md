# Horde route 30-40: loops, gaps, dungeon chains and shopping (2026-11-14)

Second pass over the Horde 30-40 chapters in `QuestHorde3040.lua` (first pass: `2026-11-12-horde-30-40.md`).
The owner asked for the Horde 1-60 loops to be polished together, smartly looped, with the gaps, optional
quests, dungeon chains and vendor or Auction House items for quests covered. This file covers the main
chapters `hillsbrad-30`, `flats-33`, `desolace-34`, `stv-35`, `dustwallow-37`, `arathi-38`, `badlands-39` and
the alternates `stv-30`, `desolace-31`, `dustwallow-33`, `badlands-37`. Every chapter stays unverified until
it is played.

## Sources

- Quest facts: the quest database Forever cache (commit 0f7d8ad) through `tools/questfacts.py` (givers, enders,
  levels, `requiredLevel`, prerequisites, item drops and vendors, NPC and object spawns). Every new coordinate
  is a quest database spawn or cluster centre unless the step carries an `uncertain` note.
- Forever client reference `tools/reference/forever.json`: every new quest ID is in the client; map extents
  for converting reference guide A's world coordinates.
- Reference guide A (reference guide A Forever Horde chapters 30-33 Hillsbrad/Arathi to 39-40 Badlands, and the dungeon
  copies 30-31 Razorfen Kraul to 39-40 Badlands): quest IDs, grouping, order and positions only, never text.
  Positions taken from it: Gemmil and the Carnivorous Weeds (Grom'gol), Skonk (Arathi), the Highway Robbery
  chain (left out, below).
- reference guide B Forever guides (quest-ID gap check only).
- Wowhead Forever: [Weed Whacked 97453](https://www.wowhead.com/forever/quest=97453) (6 Carnivorous Weeds south
  of Grom'gol, Gemmil's mother), [Anyone Can Cook 79624](https://www.wowhead.com/forever/quest=79624) (starts
  from the Illegible Recipe, ends at Skonk), [The Giant in the Den 92707](https://www.wowhead.com/forever/quest=92707)
  (the Goliath's Wristguards to Drum Fel), [The Gurubashi Legends of Old 95748](https://www.wowhead.com/forever/quest=95748).
- Method as in `2026-11-12-1-30-loops-gaps.md`: `tools/questloops.py HORDE ORC,TROLL,TAUREN,SCOURGE,SKYBORNE`
  with all nine classes, the coordinator's gap lists (quests reference guide A or reference guide B accept that no Horde section uses,
  with quest database facts) and the reference buy list (every reference guide A buy/Auction House step and reference guide B `buy` line).
- The quest log was simulated per section with the route audit's own rules (all races and classes, dungeons
  and optional steps off and on) after every change.
